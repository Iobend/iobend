# IOBend Assets

This directory contains official branding assets, logos, and screenshots for IOBend.

## Contents

- **Official Logo (`IOBend.jpg`)**: The official, authoritative IOBend logo mark.
- **Guidelines**: Official brand identity specifications detailed in [`docs/BRAND_GUIDELINES.md`](../../docs/BRAND_GUIDELINES.md).

## Usage Guidelines

When using IOBend branding materials, please adhere to the following guidelines:

1. **Do not distort the logo**: Always scale proportionally.
2. **Clear space**: Leave adequate padding around the logo so it stands out.
3. **Backgrounds**: Use the white logo variant on dark backgrounds and the dark logo variant on light backgrounds.
