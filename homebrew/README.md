# AshGrid Homebrew Tap

This directory is a placeholder for the future AshGrid Homebrew tap formula.

## Future Plans

Once the AshGrid CLI binaries are stable, we will provide a custom tap allowing macOS and Linux users to install AshGrid easily via Homebrew:

```bash
brew tap ashgrid/tap
brew install ashgrid
```

The Ruby formula (`ashgrid.rb`) will automatically download the correct architecture binary (e.g., `amd64` or `arm64`) and place it in the system path.

Stay tuned for updates!
