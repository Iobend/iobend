# CLI Reference

The IOBend CLI is designed to be intuitive, powerful, and discoverable. Below is a complete reference of all available commands.

## Core Commands

- **[`iobend doctor`](doctor.md)**: Diagnose and fix environment issues.
- **[`iobend auth`](auth.md)**: Manage authentication with cloud providers and services.
- **[`iobend generate`](generate.md)**: Scaffold new projects, pipelines, and infrastructure.
- **[`iobend container`](container.md)**: Manage local and remote containers effortlessly.
- **[`iobend mcp`](mcp.md)**: Manage Model Context Protocol integrations.

## Configuration & Utility

- **[`iobend config`](config.md)**: Manage global and project-level settings.
- **[`iobend update`](update.md)**: Update the CLI to the latest version.
- **[`iobend version`](version.md)**: Print the current CLI version.
- **[`iobend help`](help.md)**: Get detailed help for IOBend commands.

> [!TIP]
> You can append `--help` or `-h` to any command in the terminal to view its syntax and options directly in your console.
