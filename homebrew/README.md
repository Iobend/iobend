# IOBend Homebrew Tap

This directory is a placeholder for the future IOBend Homebrew tap formula.

## Future Plans

Once the IOBend CLI binaries are stable, we will provide a custom tap allowing macOS and Linux users to install IOBend easily via Homebrew:

```bash
brew tap iobend/tap
brew install iobend
```

The Ruby formula (`iobend.rb`) will automatically download the correct architecture binary (e.g., `amd64` or `arm64`) and place it in the system path.

Stay tuned for updates!
